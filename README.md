# Mini Katalog - Flutter Projesi

Bu proje, Mobil Uygulama Geliştirme eğitimi kapsamında Flutter kullanılarak geliştirilmiş temel seviyede bir e-ticaret katalog uygulaması taslağıdır[cite: 11]. Proje temel widget yapısı, sayfa geçişleri (Navigator), veri modelleme ve basit sepet yönetimi simülasyonunu içermektedir[cite: 11, 15].

## Proje Hakkında
* **Amacı:** Flutter mimarisini, widget ağacını, JSON/mock veri yapılarından model sınıfı oluşturmayı ve sayfalar arası veri taşımayı öğrenmek[cite: 11, 15].
* **Ekranlar:** 
  - Ana Sayfa (Discover & Ürün Vitrini)[cite: 15]
  - Ürün Detay Sayfası[cite: 15]
  - Sepet (Cart) Ekranı[cite: 14, 15]

## Kullanılan Teknolojiler ve Araçlar
* **Flutter SDK**[cite: 12]
* **Dart SDK**[cite: 12]
* **Geliştirme Ortamı:** Visual Studio Code[cite: 12]

## Kullanılan Flutter Sürümü
* Flutter 3.x (Stable Channel)
